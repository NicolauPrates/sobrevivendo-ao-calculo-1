## O diagnóstico de 10 minutos

Antes de abrir a Unidade 1, responda a estas oito perguntas **no papel, sem calculadora e sem consultar nada**. Elas não cobram Cálculo: cobram exatamente as ferramentas que você vai usar em *toda* questão de Cálculo 1.

1. Fatore: $x^3 - 8$.
2. Simplifique: $\dfrac{x^2 - 9}{x^2 - 6x + 9}$.
3. Racionalize: $\dfrac{1}{\sqrt{x+1} - 1}$.
4. Resolva: $\dfrac{x-1}{x+2} \geqslant 0$.
5. Quanto vale $\cos\left(\dfrac{2\pi}{3}\right)$?
6. Resolva: $\ln(x) + \ln(x-3) = \ln(4)$.
7. Escreva $\lvert x - 5 \rvert < 2$ como um intervalo.
8. Simplifique: $\dfrac{\frac{1}{x+h} - \frac{1}{x}}{h}$.

**Respostas:**

| | | | |
| :---: | --- | :---: | --- |
| 1 | $(x-2)(x^2+2x+4)$ | 5 | $-\dfrac{1}{2}$ |
| 2 | $\dfrac{x+3}{x-3}$ | 6 | $x = 4$ |
| 3 | $\dfrac{\sqrt{x+1}+1}{x}$ | 7 | $(3,\,7)$ |
| 4 | $(-\infty,-2) \cup [1,+\infty)$ | 8 | $-\dfrac{1}{x(x+h)}$ |

**Como interpretar o resultado:**

| Acertos | O que fazer |
| :---: | --- |
| 7 ou 8 | Pode ir direto para a [Unidade 1](../01-funcoes/README.md). Guarde o pré-cálculo como consulta. |
| 4 a 6 | Leia a [Revisão de Pré-Cálculo](revisao-pre-calculo.md) inteira antes de seguir. Vale cada minuto. |
| 0 a 3 | Reserve **dois dias** para o pré-cálculo antes de abrir a Unidade 1. Começar Cálculo sem isso é construir no vazio — e é o motivo número um de reprovação na disciplina. |

> [!IMPORTANT]
> A questão 8 é o quociente de Newton: **é literalmente a definição de derivada**, que você vai encontrar na Unidade 3. Quem não consegue simplificá-la hoje não vai conseguir derivar pela definição em outubro. A boa notícia é que isso se resolve em um fim de semana.
