## Como cada gabarito é organizado

> **✅ Parte 1 — Respostas finais.** Só o resultado, em tabela. É para você **conferir** se acertou.
>
> **🧠 Parte 2 — Resoluções completas.** O passo a passo comentado. É para você entender **onde** errou.

Confira a Parte 1 primeiro. Se não bater, volte ao **seu** rascunho e procure o erro antes de abrir a Parte 2 — é nesses dez minutos que o aprendizado acontece.

---

## O erro mais caro desta unidade

Não é de conta: é de **notação**. Escrever

$$\frac{x^2-9}{x-3} = x+3 = 6$$

está errado, porque $x+3$ não é $6$ — ele **tende** a $6$. O certo é carregar o símbolo até o fim:

$$\lim_{x\to3}\frac{x^2-9}{x-3} = \lim_{x\to3}(x+3) = 6$$

Professores descontam por isso, e com razão: a igualdade do meio só é verdadeira sob o limite.
