# 🧠 Parte 2 — Resoluções completas

## Bloco A · Fixação

### Exercício 1

**(a)** $\cos(5x)\cdot 5 = 5\cos(5x)$

**(b)** $-\operatorname{sen}\big(x^2\big)\cdot 2x = -2x\operatorname{sen}\big(x^2\big)$

**(c)** $e^{4x}\cdot 4 = 4e^{4x}$

**(d)** $\dfrac{1}{3x+1}\cdot 3 = \dfrac{3}{3x+1}$

**(e)** $6(2x+7)^5\cdot 2 = 12(2x+7)^5$

**(f)** $\dfrac{1}{2\sqrt{x^2+9}}\cdot 2x = \dfrac{x}{\sqrt{x^2+9}}$

---

### Exercício 2

**(a)** $\operatorname{sen}^3 x = (\operatorname{sen} x)^3$: de fora é a **potência**.

$$f' = 3\operatorname{sen}^2 x\cdot\cos x$$

**(b)** $\operatorname{sen}\big(x^3\big)$: de fora é o **seno**.

$$f' = \cos\big(x^3\big)\cdot 3x^2$$

**(c)** $(\ln x)^2$: de fora é a potência.

$$f' = 2\ln x\cdot\frac1x = \frac{2\ln x}{x}$$

**(d)** $\ln\big(x^2\big) = 2\ln x$ (quebrando antes), logo $f' = \dfrac2x$.

> 💡 Compare (a) com (b) e (c) com (d): **a mesma dupla de funções, em ordens trocadas, dá resultados completamente diferentes.** Identificar quem está por fora é o passo que decide a questão.

---

### Exercício 3

**(a)** $e^{\cos x}\cdot(-\operatorname{sen} x) = -\operatorname{sen} x\thinspace e^{\cos x}$

**(b)** $\sec^2(2x+1)\cdot 2 = 2\sec^2(2x+1)$

**(c)** $\cos^2(3x) = [\cos(3x)]^2$, três camadas:

$$f' = 2\cos(3x)\cdot(-\operatorname{sen}(3x))\cdot 3 = -6\cos(3x)\operatorname{sen}(3x)$$

---

### Exercício 4

**(a)** $f' = 1\cdot e^{2x} + x\cdot 2e^{2x} = e^{2x}(1+2x)$

**(b)** $f' = \dfrac{2\cos(2x)\cdot x - \operatorname{sen}(2x)}{x^2} = \dfrac{2x\cos(2x)-\operatorname{sen}(2x)}{x^2}$

**(c)** $f' = 2x\ln(3x) + x^2\cdot\dfrac{3}{3x} = 2x\ln(3x) + x$

---

### Exercício 5

**(a)** $2x + 2y\thinspace y' = 0 \Rightarrow y' = -\dfrac{x}{y}$

**(b)** Regra do produto à esquerda: $y + x\thinspace y' = 0 \Rightarrow y' = -\dfrac yx$

**(c)** $3y^2\thinspace y' = 1 \Rightarrow y' = \dfrac{1}{3y^2}$

---

### Exercício 6

$$f'(x) = 3x^2 \ \Longrightarrow \ f'(2) = 12$$

Como $f(2) = 9$, tem-se $f^{-1}(9) = 2$, logo

$$\big(f^{-1}\big)'(9) = \frac{1}{f'(2)} = \frac{1}{12}$$

---

### Exercício 7

**(a) Falso.** Falta o fator de dentro: $2\cos(2x)$.

**(b) Verdadeiro.**

**(c) Falso.** Como $y$ depende de $x$, obtém-se $2y\thinspace \dfrac{dy}{dx}$.

**(d) Falso.** O ponto correto é $x = f^{-1}(y)$: $\big(f^{-1}\big)'(y) = \dfrac{1}{f'\big(f^{-1}(y)\big)}$.

---

### Exercício 8

**Expandindo:** $f(x) = x^6+3x^4+3x^2+1$, logo

$$f'(x) = 6x^5+12x^3+6x$$

**Pela cadeia:**

$$f'(x) = 3\big(x^2+1\big)^2\cdot 2x = 6x\big(x^2+1\big)^2$$

**Conferindo que são iguais:** $6x\big(x^4+2x^2+1\big) = 6x^5+12x^3+6x$ ✔

> 💡 A forma **fatorada** é quase sempre preferível: ela mostra de imediato que a derivada zera só em $x=0$.

$$f(x) = \ln(x+1) - \ln(x-1)$$

$$f'(x) = \frac{1}{x+1} - \frac{1}{x-1} = \frac{(x-1)-(x+1)}{(x+1)(x-1)} = \frac{-2}{x^2-1}$$

### Exercício 13

Regra do produto, com cadeia em cada fator:

$$f'(x) = 2x\thinspace e^{x^2}\operatorname{sen}(3x) + e^{x^2}\cdot 3\cos(3x) = e^{x^2}\big[2x\operatorname{sen}(3x)+3\cos(3x)\big]$$

---

### Exercício 14

*Primeiro, confirme que o ponto está na curva:* $1+1+1 = 3$ ✔

Derivando implicitamente:

$$2x + \big(y + x\thinspace y'\big) + 2y\thinspace y' = 0 \ \Longrightarrow \ y'\big(x+2y\big) = -2x-y$$

$$y' = \frac{-2x-y}{x+2y} \ \Longrightarrow \ y'(1,1) = \frac{-3}{3} = -1$$

$$y - 1 = -1(x-1) \ \Longrightarrow \ y = -x+2$$

---

### Exercício 15

Derivando os dois lados, com cadeia à esquerda e **produto** dentro dela:

$$\cos(xy)\cdot\big(y + x\thinspace y'\big) = 1$$

$$y + x\thinspace y' = \frac{1}{\cos(xy)} \ \Longrightarrow \ x\thinspace y' = \frac{1}{\cos(xy)} - y$$

$$y' = \frac{1 - y\cos(xy)}{x\cos(xy)}$$

---

### Exercício 16

$$f'(x) = 2+\cos x \ \Longrightarrow \ f'(0) = 2+1 = 3$$

Como $f(0)=0$, tem-se $f^{-1}(0)=0$, logo

$$\big(f^{-1}\big)'(0) = \frac{1}{f'(0)} = \frac13$$

---

### Exercício 17

$$\ln y = 2\ln(x+1) + \frac12\ln(x-3) - 4\ln x$$

Derivando:

$$\frac{y'}{y} = \frac{2}{x+1} + \frac{1}{2(x-3)} - \frac4x$$

$$y' = \frac{(x+1)^2\sqrt{x-3}}{x^4}\left[\frac{2}{x+1} + \frac{1}{2(x-3)} - \frac4x\right]$$

## Bloco C · Desafio

### Exercício 19

Derivação logarítmica:

$$\ln y = \ln x\cdot\ln x = (\ln x)^2$$

$$\frac{y'}{y} = 2\ln x\cdot\frac1x$$

$$y' = x^{\ln x}\cdot\frac{2\ln x}{x}$$

---

### Exercício 20

**Hipótese.** $f$ é par e derivável: $f(-x) = f(x)$ para todo $x$ do domínio.

**Demonstração.** Derive os dois lados em relação a $x$. No lado esquerdo, a regra da cadeia dá o fator $-1$ de dentro:

$$-f'(-x) = f'(x)$$

Multiplicando por $-1$:

$$f'(-x) = -f'(x)$$

que é exatamente a definição de função **ímpar**. $\blacksquare$

> 💡 **Confira com um exemplo:** $f(x) = x^2$ é par, e $f'(x) = 2x$ é ímpar ✔ ; $\cos x$ é par, e $(\cos x)' = -\operatorname{sen} x$ é ímpar ✔. O mesmo argumento mostra que a derivada de uma função **ímpar** é **par**.

---

### Exercício 21

*Confirmando o ponto:* $1^{2/3} + \big(3\sqrt3\big)^{2/3} = 1 + \big(3^{3/2}\big)^{2/3} = 1 + 3 = 4$ ✔

**Derivando implicitamente:**

$$\frac23 x^{-1/3} + \frac23 y^{-1/3}\thinspace y' = 0 \ \Longrightarrow \ y' = -\frac{x^{-1/3}}{y^{-1/3}} = -\frac{y^{1/3}}{x^{1/3}} = -\sqrt[3]{\frac{y}{x}}$$

**No ponto $\big(1,\thinspace 3\sqrt3\big)$:**

$$y' = -\sqrt[3]{3\sqrt3} = -\sqrt[3]{3^{3/2}} = -3^{1/2} = -\sqrt3$$

**Reta tangente:**

$$y - 3\sqrt3 = -\sqrt3\thinspace (x-1) \ \Longrightarrow \ y = -\sqrt3\thinspace x + 4\sqrt3$$

> 💡 **O astroide é a curva traçada por um ponto de um círculo que rola dentro de outro.** Note que a derivada implícita funcionou mesmo sem ser possível escrever $y$ como uma função de $x$ — a curva falha no teste da reta vertical.

---

### Exercício 22

Pela regra da cadeia, com $g = f\circ f$:

$$g'(x) = f'\big(f(x)\big)\cdot f'(x)$$

Em $x=1$:

$$g'(1) = f'\big(f(1)\big)\cdot f'(1) = f'(2)\cdot f'(1) = 4\cdot 3 = 12$$

**Resposta.** $g'(1) = 12$

> ⚠️ **A armadilha** é calcular $f'(1)\cdot f'(1) = 9$. O primeiro fator é $f'$ avaliada em $f(1) = 2$, e não em $1$. Essa confusão de ponto é a mesma do Exercício 7(d).
