## Bloco A · Fixação

**1.** Derive:

&nbsp;&nbsp;**(a)** $f(x) = 3\mathrm{sen}\thinspace x$ &nbsp;&nbsp;&nbsp; **(b)** $f(x) = \cos x - 2x$ &nbsp;&nbsp;&nbsp; **(c)** $f(x) = 5e^x$

&nbsp;&nbsp;**(d)** $f(x) = 4\ln x$ &nbsp;&nbsp;&nbsp; **(e)** $f(x) = \mathrm{tg}\thinspace x + \sec x$ &nbsp;&nbsp;&nbsp; **(f)** $f(x) = 2^x$

**2.** Derive pela regra do **produto**:

&nbsp;&nbsp;**(a)** $f(x) = x\mathrm{sen}\thinspace x$ &nbsp;&nbsp;&nbsp; **(b)** $f(x) = e^x\cos x$ &nbsp;&nbsp;&nbsp; **(c)** $f(x) = x^2\ln x$

**3.** Derive pela regra do **quociente**:

&nbsp;&nbsp;**(a)** $f(x) = \dfrac{\mathrm{sen}\thinspace x}{x}$ &nbsp;&nbsp;&nbsp; **(b)** $f(x) = \dfrac{\ln x}{x}$ &nbsp;&nbsp;&nbsp; **(c)** $f(x) = \dfrac{e^x}{x+1}$

**4.** **Simplifique antes** de derivar:

&nbsp;&nbsp;**(a)** $f(x) = \ln\big(x^5\big)$ &nbsp;&nbsp;&nbsp; **(b)** $f(x) = \ln(2x)$ &nbsp;&nbsp;&nbsp; **(c)** $f(x) = e^{\ln x}$ &nbsp;&nbsp;&nbsp; **(d)** $f(x) = \dfrac{\mathrm{sen}\thinspace x}{\mathrm{tg}\thinspace x}$

**5.** Determine $f'(0)$:

&nbsp;&nbsp;**(a)** $f(x) = e^x$ &nbsp;&nbsp;&nbsp; **(b)** $f(x) = \mathrm{sen}\thinspace x$ &nbsp;&nbsp;&nbsp; **(c)** $f(x) = \cos x$ &nbsp;&nbsp;&nbsp; **(d)** $f(x) = xe^x$

**6.** Determine a reta tangente:

&nbsp;&nbsp;**(a)** a $y = \mathrm{sen}\thinspace x$ em $x=0$; &nbsp;&nbsp;&nbsp; **(b)** a $y = e^x$ em $x=0$; &nbsp;&nbsp;&nbsp; **(c)** a $y = \ln x$ em $x=1$.

**7.** Verdadeiro ou falso? Justifique.

&nbsp;&nbsp;**(a)** $\big(e^x\big)' = e^x$ &nbsp;&nbsp;&nbsp; **(b)** $(\ln x)' = \dfrac1x$ para todo $x$ real

&nbsp;&nbsp;**(c)** $(\mathrm{tg}\thinspace x)' = \sec x$ &nbsp;&nbsp;&nbsp; **(d)** $(\cos x)' = -\mathrm{sen}\thinspace x$ &nbsp;&nbsp;&nbsp; **(e)** $\big(2^x\big)' = x\thinspace 2^{x-1}$

**8.** Deduza $(\mathrm{cossec}\thinspace x)' = -\mathrm{cossec}\thinspace x\mathrm{cotg}\thinspace x$ pela regra do quociente.

## Bloco B · Consolidação

**9.** $f(x) = x^2\cos x$

**10.** $f(x) = \dfrac{\mathrm{sen}\thinspace x + \cos x}{\mathrm{sen}\thinspace x - \cos x}$ &nbsp;&nbsp;*(use $\mathrm{sen}^2+\cos^2=1$ para simplificar o resultado)*

**11.** $f(x) = e^x\ln x$

**12.** $f(x) = \dfrac{x}{\ln x}$

**13.** Determine o ponto em que a tangente ao gráfico de $f(x) = e^x - x$ é horizontal.

**14.** $f(x) = \dfrac{\sec x}{x}$

**15.** Demonstre, **pela definição**, que $(\cos x)' = -\mathrm{sen}\thinspace x$.

**16.** Determine a reta tangente a $y = x\mathrm{sen}\thinspace x$ no ponto de abscissa $x = \dfrac{\pi}{2}$.

**17.** Verifique que:

&nbsp;&nbsp;**(a)** $y = \mathrm{sen}\thinspace x$ satisfaz $y'' + y = 0$;

&nbsp;&nbsp;**(b)** $y = e^x$ satisfaz $y'' - y = 0$.

**18.** $f(x) = \big(x^2+1\big)e^x$ &nbsp;&nbsp;*(fatore o resultado)*

## Bloco C · Desafio

**19.** Usando a reescrita $u^{v} = e^{v\ln u}$, derive $f(x) = x^{\mathrm{sen}\thinspace x}$, para $x>0$.

**20.** Seja $f(x) = \mathrm{sen}\thinspace x$.

&nbsp;&nbsp;**(a)** Calcule $f'$, $f''$, $f'''$ e $f^{(4)}$, e identifique o padrão.

&nbsp;&nbsp;**(b)** Determine $f^{(2026)}(x)$.

**21.** Determine $a$ e $b$ para que $f$ seja **derivável** em $x=0$:

$$
f(x) = \begin{cases}
a\thinspace e^x, & \text{se } x < 0 \\
b + \mathrm{sen}\thinspace x, & \text{se } x \geqslant 0
\end{cases}
$$

**22.** Seja $f(x) = e^x\mathrm{sen}\thinspace x$. Mostre que

$$f'' - 2f' + 2f = 0$$
